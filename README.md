# Career Craft

This project has been refactored into a separate frontend and backend structure.

## Structure

- **frontend/**: Contains the Next.js application.
- **backend/**: Contains the Firebase Functions and backend logic.

## Getting Started

### Frontend
To run the frontend application:

```bash
cd frontend
npm run dev
```

The application will start on [http://localhost:3000](http://localhost:3000).

### Backend
To run the backend emulators:

```bash
cd backend
npm run dev
```

This runs `firebase emulators:start` under the hood.
